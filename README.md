# PS4JB

PS4 jailbreak / HEN host UI by **X-F1REBALL-X**.

**Live site:** [https://x-f1reball-x.github.io/PS4JB/](https://x-f1reball-x.github.io/PS4JB/)

## Supported firmwares

- 13.02
- 13.04
- 13.50
- 13.52

## How to use

1. Open the site on your PS4 browser.
2. Wait for the countdown, then press **X** / tap **Press X to start**.
3. Stay on the page while the jailbreak runs (`Jailbreak in progress`).
4. On success you should see **Jailbreak completed successfully**.
5. If it fails, restart the console and try again.

## Notes

- Clear the browser cache (or reopen the browser) after site updates so the PS4 loads the latest files.
- Closing the browser from the page is not supported by the PS4 WebKit browser.
